# CS3090-Block-2
This (hypothetical) repository would be used to store games I've created for game jams. Because I want to share these games with a wide audience for free, I've chosen an open-source license. While I'm fine with individuals modifying and remixing these games, I don't want them to charge for any modifications made to my games, so I licensed this repository under GPLv3 so that the protections provided by a strong copyleft license ensure that no one can profit off of these games. I chose GPLv3 (instead of a different strong copyleft license) because of its explicit free usage rights and its clause about allowing individuals to break any DRM code within the project to ensure that individuals can always access this software and any modifications made to it for free.
